# EN home snapshots

Frozen reference copies of the English locale home — not served by the site.

| Folder | What it is | Git tag |
| --- | --- | --- |
| `en-home-production/` | Classic EN landing as on `main` / production | `snapshot/en-home-production` |
| `en-home-proposal/` | Homepage proposal layout (bubbles + What’s new + feature cards + Featured) | `snapshot/en-home-proposal` |

Each folder holds the page HTML and its landing stylesheet. Live pages also load `/css/base.css` and `/css/content-header.css` from `public/`.
