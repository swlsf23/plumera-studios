# Learn *avoir*

*Avoir* is one of the most important French verbs, and one you'll use constantly. The closest English meaning is "to have," but French also uses *avoir* in many places where English uses *be*. You don't need to learn all of its uses at once. Start with the core A1 uses, then build your range with common expressions and the mistakes that can send English *be* to the wrong French verb.

## Summary of *avoir*

As you progress, *avoir* expands from its most basic uses into fixed phrases and contrasts with *être*:

| Level | Pattern | Meaning or use |
|---|---|---|
| A1 | *avoir* + something | have or own something |
| A1 | *il y a* | say that something exists or is present |
| A1 | *avoir* + age + *ans* | say how old someone is |
| A1 | *avoir* + noun | express hunger, thirst, cold, fear, and similar states |
| A1 | *avoir* + past participle | form the past tense with most verbs |
| A2 | *avoir raison* / *avoir tort* | be right or wrong |
| A2 | *avoir envie de* | want something or feel like doing something |
| A2 | *avoir besoin de* | need something or need to do something |
| A2 | *avoir de la chance* | be lucky |

You don't need to learn all of these uses at once. Follow the learning path above and build on the patterns you already know.
