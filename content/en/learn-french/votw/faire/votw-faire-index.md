## Summary of *faire*

As you progress, *faire* expands from its most basic uses into a wider range of expressions and constructions:

| Level | Pattern | Meaning or use |
|---|---|---|
| A2 | *faire* + something | do or make something |
| A2 | *il fait* + weather expression | talk about the weather |
| A2 | *faire* + activity | talk about activities |
| A2 | *faire attention à* | pay attention to |
| A2 | *ça fait... que* | say how long something has been happening |
| B1 | *faire* + infinitive | have something done |
| B1 | *se faire* + infinitive | have something happen to you |
| B1 | *faire confiance à* | trust |
| B1 | *faire semblant de* | pretend to |
| B1 | *faire face à* | face or cope with something |

You don't need to learn all of these uses at once. Follow the learning path above and build on the patterns you already know.
