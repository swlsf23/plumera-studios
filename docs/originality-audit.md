# Plumera Originality Audit (POA)

## Purpose

The Plumera Originality Audit ensures that each published article:

-   uses original explanations and wording,
-   avoids unintentionally echoing existing educational resources,
-   develops a distinctive Plumera teaching voice,
-   recognizes that factual language and common pedagogical ideas are
    often overlap across language-learning materials.

This audit evaluates **expression**, not ownership of facts or
grammatical concepts.

------------------------------------------------------------------------

# Scope

Perform this audit for articles that contain substantial instructional
content, including:

-   Verb of the Week
-   Grammar
-   Usage
-   Vocabulary
-   False friends
-   Pronunciation
-   Cultural explanations

Do not perform it for:

-   announcements
-   release notes
-   UI documentation
-   marketing copy
-   navigation pages

------------------------------------------------------------------------

# Phase 1 -- Instructional Review

Read the article as a learner.

Evaluate:

-   conceptual gaps,
-   misleading explanations,
-   sequencing,
-   CEFR appropriateness,
-   whether each explanation naturally prepares the learner for the
    next.

Do **not** comment on style unless it affects learning.

------------------------------------------------------------------------

# Phase 2 -- Originality Classification

Classify every paragraph.

## Conventional Factual Explanation

Characteristics

-   objective facts,
-   unavoidable terminology,
-   standard grammar explanations,
-   dictionary-level information.

Examples

-   *prendre* is an irregular verb.
-   The past participle is *pris*.
-   Transport normally takes the definite article.

**Action**

No originality search required.

------------------------------------------------------------------------

## Common Pedagogical Idea

Characteristics

A teaching insight commonly shared by experienced French teachers.

Examples

-   French often uses *prendre* where English uses *have*.
-   Explaining *prendre un café* versus *boire un café*.
-   Organizing meanings around a core semantic idea instead of a list of
    translations.

**Action**

Determine whether the wording appears original.

Search only if the phrasing feels unusually distinctive.

------------------------------------------------------------------------

## Distinctive Phrasing

Characteristics

Sentences that are memorable, elegant, concise, or quote-worthy.

Examples

> *Boire* is the physical act of drinking. *Prendre* is the occasion.

> French names the transport as the thing you take.

**Action**

Perform a detailed originality search.

------------------------------------------------------------------------

## Plumera Voice

Flag explanations that feel uniquely Plumera.

Characteristics

-   elegant mental models,
-   memorable explanations,
-   original analogies,
-   distinctive teaching style.

**Recommendation**

Protect these during editing.

These become part of Plumera's teaching identity.

------------------------------------------------------------------------

# Phase 3 -- Originality Search

Only perform searches for Distinctive Phrasing passages (and occasionally
Common Pedagogical Idea passages if warranted).

For each passage:

## Exact Searches

Search:

-   the complete sentence in quotation marks,
-   shortened fragments,
-   key clauses,
-   variants with punctuation removed.

## Conceptual Searches

Search the underlying teaching idea rather than only the wording.

Example:

Instead of searching:

> *Prendre* is the occasion.

Search:

-   boire prendre difference
-   prendre un café explanation
-   why French says prendre un café
-   French boire vs prendre

Read the explanations, not just the search snippets.

## Similarity Assessment

### Original Expression

The instructional idea is common.

The wording appears original.

**Recommendation:** Keep.

### Similar Explanation

The idea appears in many sources.

The wording remains substantially different.

**Recommendation:** Keep.

### Close Wording

A source contains substantially similar wording or sentence structure.

**Recommendation:** Rewrite.

------------------------------------------------------------------------

# Phase 4 -- Report

Produce the following report.

## Pedagogical Review

-   Conceptual issues
-   Sequencing issues
-   CEFR appropriateness

## Originality Review

### Conventional

List paragraphs requiring no search.

### Common Ideas

List common instructional ideas.

### Distinctive Phrasing

For each passage report:

-   searched phrases,
-   sources consulted,
-   closest conceptual matches,
-   closest wording matches,
-   recommendation.

### Plumera Voice

List explanations worth preserving because they strengthen Plumera's
identity.

------------------------------------------------------------------------

# Editorial Principles

The audit should **not**:

-   reward novelty over clarity,
-   recommend rewriting merely because another teacher explains the same
    concept,
-   penalize unavoidable grammatical terminology,
-   encourage rewriting factual statements into unnatural wording.

The audit should:

-   protect original educational writing,
-   identify wording that is too close to existing sources,
-   preserve clear explanations,
-   help Plumera develop a consistent and recognizable teaching voice.

------------------------------------------------------------------------

# Plumera Voice Ledger

Maintain a running list of Plumera Voice explanations across all
published articles.

Over time, this ledger becomes an internal style guide documenting
Plumera's recurring teaching patterns, mental models, and distinctive
voice.
